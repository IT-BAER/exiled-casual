Privacy

Exiled Casual counts how the game is doing. It does not keep a file on you.

What is collected

While the game is open it sends small reports to its own server:

  • That a session started, with your screen size, pixel density, graphics card name, browser language, whether it runs as an installed app, the number of processor cores, the approximate memory of the device and whether it has a touch screen.
  • Which website sent you here (the host name only, for example the search engine) and which version of the game you run.
  • Which screen you are on (menu, character select, game and so on) and how long the game stayed visible, reported every 30 seconds while the tab is in front.
  • How smoothly the game runs: the typical and the slowest frame rate, and how long the menu and the world took to appear.
  • For the character you play: its class, its level and how old it is, grouped as 0, 1, 2 to 6, 7 to 29 or 30 and more days. This is how we tell whether people come back.
  • Game events: entering the hideout or a map, finishing a map, gaining a level, dying (and which monster and element did it), and how many items of each rarity dropped.
  • Errors: the error message and where in the code it happened, so it can be fixed.

When the report arrives, Cloudflare tells the server which country, region and city the request came from and approximate coordinates of that place. Your IP address is shortened (the last part is cut off: to a /24 for IPv4, to a /48 for IPv6) before it is kept. The server also records your browser, operating system and graphics card.

What is not collected

  • No cookies and no identifier stored on your device. Nothing is written to local storage, IndexedDB or the cache for this purpose.
  • No names. The names you give your characters, and the names of items, never leave your device.
  • No tracking across days. A random session number exists only in memory for as long as the page stays open. To tell whether a visit is the same as another one on the same day, the server uses a short-lived code made from your shortened address and browser, with a secret that is thrown away every 24 hours. After that it cannot be linked.
  • No third parties, other than Cloudflare, which delivers the site as a content network and therefore sees your requests.

Why

To keep the game healthy: to find and fix errors, to balance the game, to see how many players the server must carry and to see which devices need a lighter picture.

How long

Raw events are kept for 90 days. After that only daily totals remain, which cannot be traced to a session.

How to opt out

Turn on Global Privacy Control or Do Not Track in your browser. The game then sends nothing at all. Nothing else needs to be done, and the game plays the same.

Legal basis

Legitimate interest, Article 6(1)(f) of the GDPR: running and improving a free game, with data kept as small and as short-lived as the above. You may object at any time; see below.

Contact

Questions, requests to see or remove data, and objections: open an issue at github.com/IT-BAER/exiled-casual/issues. Do not post personal details there; say what you need and we will arrange the rest.
